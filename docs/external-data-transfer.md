# 외부 전송 항목

2026-11-16 기준. 서비스가 회사 밖 업체로 보내는 데이터를 기능별로 적는다. 개인정보처리방침의 처리 위탁·국외 이전 공개 항목과 보안 심의 자료는 이 표에서 만든다.
처리 위치(국가)와 보관 조건은 업체 계약·콘솔 설정에서 확인하고 이 문서에는 적지 않는다.
얼굴·번호판·위치정보 처리, 외부 VLM 전송, 보관·삭제 정책은 README 「협업·데이터 관리」대로 실데이터 연동 전에 확정한다.
기능을 더하거나 보내는 칸을 바꾸면 이 문서도 같이 고친다.

## 1. 외부 AI(OpenAI)

| 기능 | 코드 | API | 보내는 것 | 사람을 특정할 수 있는 것 | 지금 막는 것 |
| --- | --- | --- | --- | --- | --- |
| 영상 분석(사실 카드) | `workers/vision/vlm.py` | chat.completions(gpt-4o, 이미지) | 사고 영상에서 뽑은 사진(JPEG)과 정해진 질문 | 번호판·얼굴·간판(장소) | 없음(가림 처리 없음, 5절 1) |
| 배정 에이전트 | `app/agents/dispatch.py` | chat.completions | 접수 글(사고 장소·내용), 다친 사람 수·정도, 차종·차량 수·예상 손해액, 가입 담보, 계약자 이력(최근 3년 사고·민원 횟수, 장기 고객 여부), 후보 표시·진행 중 사건 수(사건에 따라 경력·맞는 전문 분야) | 접수 글 속 이름·주소, 다친 정도(건강 정보) | 번호 가림, 담당자 이름 대신 표시(3절) |
| 반박 검토 | `app/validation/rebuttal.py` | chat.completions | 담당자가 확인한 카드 칸 값(정해진 값), 고른 도표와 차순위 도표 | 없음(자유 문장 없음) | - |
| 질의응답 | `app/agents/qa.py` | chat.completions | 담당자 질문, 공식 판단 요약·로그(도표·과실비율·사고 일자·확인한 칸 값), 검색 결과 발췌(코퍼스 원문 400자), 가정 실행 결과 | 질문 속 이름·주소 | 번호 가림(3절) |
| 검색 질의 임베딩 | `app/retrieval/embedding.py` | embeddings(text-embedding-3-small) | 검색 문장. 인정기준은 카드 값 낱말, 질의응답은 LLM이 만든 문장(최대 500자) | 질의응답 검색 문장 속 이름·주소 | 번호 가림(질의응답) |
| 코퍼스 색인 임베딩 | `app/ingestion/embed.py` | embeddings | 약관·인정기준·결정례 원문 청크(적재할 때) | 없음(고객 정보 아님) | - |

chat.completions의 모델은 환경 변수로 정한다(배정·질의응답·반박 검토). OpenAI는 API 데이터를 기본적으로 학습에 쓰지 않지만, 조직 설정에서 데이터 공유를 켜면 쓴다(5절 2).

## 3. 보내기 전에 가리는 것

- `app/privacy.py`의 `mask_identifiers`가 OpenAI로 가는 자유 문장에서 이메일, 주민등록번호·외국인등록번호, 전화번호, 차량번호를 `[이메일]`·`[주민등록번호]`·`[전화번호]`·`[차량번호]`로 바꾼다. 쓰는 곳은 질의응답의 질문·검색 문장과 배정 에이전트의 접수 글(장소·내용)이다. DB에 저장하는 원문은 그대로다.
- 가리지 못하는 것: 이름·주소(모양이 정해져 있지 않다). `12도 3456`처럼 차량번호 용도 글자와 같은 글자가 들어간 글은 차량번호로 가려질 수 있다.
- 배정 에이전트는 후보를 표시(P1·I2…)로만 보낸다. 이름이 없는 계정은 저장소가 이름 자리에 이메일을 넣으므로(`app/dispatch/repository.py`) 이름 칸 자체를 보내지 않는다. LLM이 쓴 까닭 글의 표시는 저장할 때 이름으로 바꾼다.

## 5. 실데이터 연동 전에 할 일

1. 영상 사진의 번호판·얼굴 가림(워커). 가린 사진으로 카드 정확도를 다시 잰다.
2. OpenAI 조직 설정: 운영 BE와 Modal 워커 키가 속한 조직의 Data controls에서 데이터 공유가 꺼져 있는지 조직 소유자가 확인한다. 무보관(Zero Data Retention) 승인과 한국 데이터 상주를 받는다. 무보관 자격은 엔드포인트마다 다르다.
3. 개인정보처리방침: 1·2절 업체를 처리 위탁으로 공개한다. 처리 위치가 국외면 국외 이전 항목을 공개하거나 동의를 받는다. 다친 정도·진단서 같은 건강 정보는 별도 동의를 받는다.
4. 보험사 안에서 쓴다면 금융 규제(망분리·신용정보법) 절차를 밟는다.
5. 4절 평가 스크립트가 AI Hub 영상에서 뽑은 사진을 VLM API로 보내는 것이 AI Hub 이용 조건에 맞는지 확인한다. `evals/vision/README.md`는 "AI Hub 영상은 외부로 보내지 않는다"고 적고 있다.
