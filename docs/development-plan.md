## 마감일 완료 기준

- 정지원: 영상/수동 접수 → 사실 카드 검토/수정/확정, 원값·증거·매핑·버전/권한 검증.
- 구준휘: 확정 카드 → 검색·질문/재개·검증 3겹 → 세 판정 상태, QA/가정 결과는 공식 결과와 분리.
- 김지은: 세 코퍼스 PDF→청킹→문서 임베딩→색인, 검색툴 3개·검수한 평가셋/검색 결과·원문 추적.
- 옥석현: 공통 RAG·검토 초안/승인·자차 산정·구상 PDF/JSON, 근거·규칙/입력 버전·금액 상태 일치.
- FE: 같은 담당의 화면/타입/견본/API 연결, 확인·보류·실패·버전 충돌·재접속 경로 재현.

## 일정 위험과 점검 시점

11/6 MVP 도표 범위는 `docs/contracts/mvp-chart-scope.md`로 확정했다(회전교차로 포함 여부·도표 ID 목록은 후속).
11/6까지 김지은은 원문 이용조건·검수자·표본, 구준휘는 인증/DB/모델 키, 옥석현은 금액 산식/구상 서식 검수 경로를 확인한다.
11/9에 선행 MVP 연결이 안 되면 통합을 먼저 해결하고, 11/10에 확장 기능 합류 가능 여부를 다시 점검한다.
변경이 필요하면 기능별 영향·남은 작업·대체 검증을 명시해 팀과 범위를 조정한다.
미검수 산식·임의 근거·빈 정답 평가·목업을 구현 완료로 표시하지 않는다.
실데이터/키/검수 부족은 해당 기능의 미완료 사유로 기록한다.
