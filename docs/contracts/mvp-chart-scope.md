# MVP 도표 범위 결정

결정일: 2026-11-06. 근거: 정지원(비전·사실 카드) 의견, 팀 합의.
대상 코퍼스: `fault_standards`(과실비율 인정기준). 적용판(`edition`)은 C가 원문 이용조건 확인 후 manifest에 기록한다.
이 문서는 A 카드 옵션, B 질문 분기·도표 선택, C 레코드 스키마·평가셋, D 검색 필터가 공유하는 단일 기준이다.

## 범위

| 축 | 결정 | 조건 |
| --- | --- | --- |
| 사고 당사자 | 차대차만 | 차대보행자·차대이륜·차대자전거는 MVP 밖 |
| 장소·상황 | 교차로 전체: 신호 있음, 신호 없음(동일폭·대로소로·일시정지) | 카드 칸 `location_type`, `road_priority`로 판별 |
| ↳ 일방통행 | MVP 밖 | 카드에 칸 없음. 넣으려면 A가 칸을 추가한 뒤 재논의 |
| ↳ 회전교차로 | **미정** | 카드 칸은 있음. 팀 결정 필요 |
| 진행 조합 | 직진·좌회전·우회전·유턴 전 조합 | `movement_A/B` 자동 판정 정확도 약 40%. **담당자 확인 질문 필수** |
| 수정요소: 야간 | 포함 | 영상 판정 가능 |
| 수정요소: 신호위반 | 조건부 포함 | `signal_A/B`가 `human_confirmed`인 경우에만 적용 |
| 수정요소: 과속 | 제외 | 카드에 속도 칸 없음. 영상으로 과속을 판정하지 않는다(README 원칙) |
| 수정요소: 서행 불이행 | 제외 (담당자 수동 입력 시에만) | 속도 변화 판단 약함. 자동 판정하지 않는다 |
| 그 외 (차로변경·추월·주차장·진로변경·후진·개문, 중과실·현저한 과실 목록) | MVP 밖 | 해당 카드는 보류 응답 |

## 도표 선택에 쓰는 카드 칸

| 판단 정보 | 카드 칸 | 자동 정확도 (gpt-4o, 개선용 10건) | 도표 선택 전 요구 상태 |
| --- | --- | --- | --- |
| 교차로 종류 | `location_type` | 60% | `human_confirmed` |
| 도로 관계 (동일폭·대로소로·일시정지) | `road_priority` | 60% | `human_confirmed` (신호 없는 교차로일 때) |
| 진행 방향 | `movement_A`, `movement_B` | 40% | `human_confirmed` (항상 질문) |
| 신호 | `signal_A`, `signal_B` | 70% / 30% | `human_confirmed` (신호 있는 교차로·신호위반 적용 시) |
| 진입 순서 | `entry_order` | 60% | 신호 없는 교차로에서만 사용 |
| 야간 | (A가 칸 이름 확정) | — | 수정요소 적용 시 확인 |

정확도는 10건 기준 참고값이며 평가 결과가 아니다. AI Hub 영상 438건 기준 측정값(gpt-5.4-mini)은 `evals/vision/README.md` 결과 절에 있다. 모든 칸의 `model_confidence`는 참고용이고, 도표 선택은 `verification_status="human_confirmed"`인 값만 사용한다.
칸 허용값(enum)·보류 사유·필수 확인 칸은 `app/schemas/chart_scope.py`에 코드로 둔다. A가 칸 이름을 확정하면 이 모듈과 문서를 함께 바꾸고 `make contracts`로 견본을 재생성한다. 범위 게이트는 `app/workflow/graph.py`의 `scope_gate`가 담당한다. C의 도표 레코드는 같은 enum으로 속성을 기록해야 필터 검색이 맞물린다.

## 범위 밖·미확인 처리

- 범위 밖 사고 유형: `status="deferred"`, 보류 사유 "MVP 범위 밖 사고 유형(도표 미적재)".
- 필수 칸이 `human_confirmed`가 아님: 판단을 진행하지 않고 해당 칸 질문(`QuestionAnswer`)으로 분기.
- 범위 안인데 일치 도표 없음: 기존 사유 "검수한 도표 근거 없음".
- 과속·서행 불이행은 수정요소 후보에 올리지 않는다. 담당자가 수동 입력한 경우에만 산정 로그에 "담당자 입력" 출처로 기록한다.

## 후속 작업

- C: 인정기준 목차에서 위 범위에 해당하는 도표 ID 목록과 개수를 세어 이 문서에 추가한다. 11/9 검수 완료 목표량은 그 수로 정한다.
- A: `one_way`(일방통행)·야간 칸 추가 여부와 enum 확정.
- 팀: 회전교차로 포함 여부 결정.
- C·B: 범위 내 도표마다 정답 카드 1~2건으로 평가셋 작성.
