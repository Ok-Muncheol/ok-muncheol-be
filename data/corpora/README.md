# 세 코퍼스 — C 담당

- `fault_standards`: 과실비율 인정기준·도표·수정요소·관계·참고 판례
- `dispute_cases`: 분쟁심의 결정례·사실·쟁점·결정 이유
- `policy_terms`: 약관·보상 지침·담보·조항·예외 (1차 확장)

각 `manifest.example.json`은 원문/이용조건/검수/임베딩 메타데이터 양식이다.
파싱·청킹·문서 임베딩은 `app/ingestion/`, 온라인 질의 임베딩·검색은 D의 `app/retrieval/`를 사용한다.
문서 모델/차원/버전은 D와 합의한다. 약관 적용판은 사고 일자만으로 결정하지 않고 계약 자료를 확인한다.
도표 숫자·가감치·조건·중복/배타는 원문과 대조한 별도 구조 레코드로 만든다.

원본 PDF·OCR 결과·임베딩 덤프는 `data/private/` 등 무시 경로에 보관한다. 공개 저장소에 넣지 않는다.
현재 원문 수집·검수·색인 적재는 완료되지 않았다.
