# DB·RLS 마이그레이션 계획

아직 실행할 SQL은 없다. 옥석현이 통합하고 정지원·구준휘·김지은이 자기 계약을 제공한다.

| 담당 | 테이블/규칙 초안 |
| --- | --- |
| 정지원 | 사건·파일·작업·사실 카드 버전·수정/확정 이력, 담당 사건/Storage RLS |
| 구준휘 | 판단 실행·체크포인트·질문/답변·검증 로그·멱등성 |
| 김지은 | 도표·수정요소·관계·참고 판례·결정례·약관·문서/청크·임베딩 메타데이터 |
| 옥석현 | 공통 검색 함수·인덱스·코퍼스별 통계, 산정·보고서·승인·구상 버전 |

타 담당 사건/파일 차단, 서버 전용 비밀키, 카드/판단/보고서 버전 외래키, 중복 실행 방지를 검수한다.
pgvector 차원·pg_trgm·Kiwi 토큰 통계는 김지은·옥석현 계약 후 SQL로 확정한다.
lumi의 논문·웰니스 테이블을 복제하지 않는다.
