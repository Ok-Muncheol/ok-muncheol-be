# 과실비율 검토 초안 — 템플릿 설계

옥석현 담당. 아래는 출력 항목이며 구현된 템플릿 엔진 문법이 아니다.

1. 판정 상태: 초안 작성 가능 / 추가 확인 필요 / 판단 보류와 사유
2. 확정 사실·근거 키프레임·담당자 수정 이력
3. 적용 도표·차순위 후보·선택/제외 이유·도표 ID/적용판/원문 페이지
4. 기본 과실 A:B와 검수된 구조 레코드
5. 적용/미적용/불명 수정요소·가감치·근거
6. 최종 과실비율 초안·코드 계산 로그
7. 추가 확인 사항·담당자 질문·미해결 반박
8. 손해액·보험금·자기부담금·약관/서류/규칙 버전 (1차 확장)
9. 구상 예정액·실제 청구액·회수액·고객 자기부담금 검토액·필수 서류 (1차 확장)

공통 메타데이터: 사건·카드·판단·보고서 버전, 작성/확인 완료 시각·담당자, 입력 자료·규칙 버전.
확인/보류 시 4~6의 미확정 수치를 비워 둔다. 담당자 확인 완료 전에는 '검토 초안'으로 표시하고, 구상 청구서는 확인 완료 후에만 만든다.
